Put wallpaper files in this folder, then list them in catalog.json:
  { "name": "My wallpaper", "type": "video" | "image" | "youtube", "src": "/wallpapers/file.mp4", "thumb": "/wallpapers/file.jpg" }
Everything listed shows up in Settings > Wallpaper Studio > Import real wallpapers for every visitor.
Only add files you have the rights to share.
